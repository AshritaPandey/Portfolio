# Ashrita Pandey - Developer Portfolio

A sleek, premium dark-themed portfolio website showcasing my experience in Software Development, Artificial Intelligence, and Data Analytics. Built entirely from scratch without external CSS frameworks to ensure maximum performance and bespoke styling.

## ✨ Features

- **Premium Dark Aesthetic**: Custom-built, high-contrast dark theme with vibrant neon pink/red accents (`#FF204E`).
- **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices using CSS Grid and Flexbox.
- **Dynamic Project Showcases**: Custom JavaScript-driven image carousels for each project card.
- **Interactive Timeline**: An elegant, glowing vertical timeline tracking professional experience.
- **Serverless Contact Form**: Fully functional AJAX contact form integrated with [Web3Forms](https://web3forms.com/) that delivers messages directly to my email without any backend infrastructure.
- **Micro-Animations**: Smooth scroll behaviors, glowing hover effects, and CSS transitions to provide a premium user experience.

## 🛠️ Technology Stack

- **HTML5**: Semantic structure and clean markup.
- **Vanilla CSS3**: Custom styling, animations, flexbox/grid layouts, and CSS variables.
- **JavaScript (ES6+)**: Slideshow logic, smooth scrolling, and asynchronous form submission (Fetch API).
- **SVG**: Scalable vector icons for flawless rendering of social links.

## 📬 Contact Setup (For developers cloning this repo)

If you wish to fork this template and use the contact form, you will need to:
1. Get a free API key from [Web3Forms](https://web3forms.com/).
2. Open `index.html`.
3. Locate the hidden input for `access_key` in the Contact Section.
4. Replace the `value` with your unique Web3Forms API key.
